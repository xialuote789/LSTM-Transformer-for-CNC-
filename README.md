# LSTM-Transformer-for-CNC-
Code of AI application for CNC anomaly detection  
All experiments were implemented in PyTorch and conducted on an NVIDIA A100GPU. The CNC vibration dataset used in this study is publicly available at: https://github.com/boschresearch/CNC_Machining.If you wish to reproduce the results of this paper, please execute the code sequentially according to the numerical order of the 12 provided TXT files.
